# 진행 상태

기준일: 2026-09-12. 공개 가능한 구현·검증 요약이며 로컬 실행 로그가 아니다.

| 단계 | 상태 | 확인한 범위 |
|---|---|---|
| Fabric / Docker 기반 | 구현 | 인증된 브리지, 관측 polling, 실행 큐, 결과 기록 |
| 환경 관측 | 실게임 확인 | 로컬 블록 격자, 엔티티, 조준 대상, 인벤토리 |
| 직접 행동 / Astra 단일 계획 | 실게임 확인 | 시선·이동과 단일 계획 호출 |
| 단일 블록 채굴 | 실게임 확인 | 바닐라 채굴 진행과 블록 변화 |
| 평지 접근 / 아이템 수집 | 수정 후 실게임 확인 | 실제 몸체 충돌, 감속, 서버 획득 이벤트와 인벤토리 증가 |
| wood 목표 | 전체 연결 실게임 확인 | approach→mine→collect, 최초 대비 원목 +1 |
| 스킬 저장·선택 / 제작 / 자율 반복 | 미구현 | 개발 계획 참조 |

## 최신 수정

불필요한 0.15블록 여유 폭으로 정상적인 벽 접촉을 거절한 문제를 수정했다.
경유점 전환에 속도 조건과 감속을 도입하고 발 높이+2의 남은 원목을 목표 후보로 허용했다.
실패 블록·검사 종류를 결과에 포함하고 wood 기본 출력을 결과 중심으로 줄였다.
[원인과 검증](NAVIGATION_FIX.md)에 상세히 설명한다.

## 검증 기준선

- Fabric 빌드 및 Java 20개 테스트 통과.
- 별도 Docker agent의 Python 56개 테스트 통과.
- Node 10개 테스트는 직전 변경에서 통과; 그 뒤 Node 코드 변경 없음.
- 동일 실패 위치의 드롭 획득 두 번과 원목 목표 전체 연결 성공을 실게임에서 확인.
- 오류 수정 검증에는 유료 모델 호출을 사용하지 않음.

행동 종료, 블록 파괴, 아이템 획득, 고수준 목표 성공은 서로 다른 판정이다.
획득은 이벤트와 인벤토리 증거를, wood 목표는 실행 시작 대비 인벤토리 순증가를 사용한다.
원본 에피소드는 로컬 전용이며 공개 문서에는 세션 ID, 개인 경로, 원본 월드 관측을 싣지 않는다.

## 남은 제약

Docker 소스는 이 Fabric 저장소 외부에 있어 현재 Push만으로 전체 프로젝트가 보존되지 않는다.
경로는 짧은 평지만 지원하며 점프·계단·장거리 탐험·제작·스킬 학습은 미구현이다.
stop은 실행 중 큐를 선점하지 못하므로 원격 비상정지와 취소 확인이 필요하다.
다음 작업의 우선순위와 완료 기준은 [ROADMAP](ROADMAP.md)을 따른다.
