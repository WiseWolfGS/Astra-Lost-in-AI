# 진행 상태

기준일: 2026-09-13. 현재 구현과 검증 결과의 기준 문서다. 과거 수정 보고서는 당시 결과를 기록한다.

## 구현과 검증

| 기능 | 현재 상태 | 근거와 제약 |
|---|---|---|
| Fabric / Docker 기반 | 구현·운영 확인 | 인증된 관측 polling, 실행 큐, 결과 기록; 운영 설정은 docker/.env |
| 관측·직접 행동·Astra 단일 계획 | 실게임 확인 | 로컬 블록·엔티티·인벤토리, 제한된 행동과 단일 호출 |
| 채굴·평지 접근·수집 | 실게임 확인 | 블록 변화, 획득 이벤트와 인벤토리 증가 |
| 실행 중 취소 | 사용자 실게임 성공 확인 | ID·세션 확인, 입력 해제 응답, 후속 행동 억제 |
| 버전별 스킬 등록 | 구현·실게임 확인 | 현재 wood@1.1.0; 목록·조건 검사·버전 지정 실행·에피소드 기록 |
| 수집 위치·후보 재탐색 | 구현·자동 검증 | 반경 확대 탐색 및 대체 후보 분기의 실게임 확인은 잔여 |
| 핫바 슬롯 선택 | 사용자 실게임 성공 확인 | 관측 아이템 ID 검사와 선택 패킷 전송 |
| 2×2 제작 | 사용자 실게임 성공 확인 | 판자·막대·작업대 순차 제작; 서버 슬롯 패킷 검증 및 재료/산출물 일치 확인 |
| 작업대 설치 | 사용자 실게임 성공 확인 | 윗면 단일 설치, 인벤토리 소모·블록 관측 |
| 작업대 3×3 나무 도구 제작 | 사용자 실게임 성공 확인 | 화면 열기·제작·재료별 검증·닫기 |
| 일반 인벤토리 → 핫바 교환 | 사용자 실게임 성공 확인 | 양쪽 스택·서버 패킷 검증 |
| 자동 목표 선택·자율 반복 | 미구현 | [개발 계획](ROADMAP.md) 참조 |

## 현재 검증 기준선

- Fabric build와 Java 37개, Python 129개, Node 26개 테스트 통과.
- 격리된 합성 연결·실행 중 취소 시험, 보고서 회수와 테스트 환경 정리 통과.
- 사용자가 이전 커밋의 GitHub CI 두 작업과 보고서 성공을 확인. 이번 미커밋 변경의 원격 CI는 Push 후 확인.
- 운영 기록의 wood@1.1.0 실행 5건 중 원목 획득 성공 3건, 후보 선택 중단 2건 확인.
- 두 중단은 높이 +3블록 또는 수평 거리 약 5.17블록으로 선택 범위를 벗어난 경우이며 행동 전송 전에 종료.
- 성공 기록의 collect 탐색은 passes=1. 반경 확대 passes=2와 대체 후보 분기의 실게임 성공을 뜻하지 않음.
- 이번 취소·스킬·경로 변경의 검증에는 유료 모델 호출을 사용하지 않음.

행동 완료, 블록 파괴, 아이템 획득, 목표 성공은 서로 다른 판정이다.
wood 성공은 최초 대비 원목 인벤토리 순증가이며, 취소 확인은 입력 해제 응답으로 판단한다.

## 변경 내용과 관련 문서

- [핫바 이동](HOTBAR_TRANSFER.md): 일반 인벤토리의 제작 도구를 핫바로 옮기고 기존 스택을 보존한다.
- [작업대 도구 제작](WORKBENCH_CRAFTING.md): handler별 슬롯 증거와 판자·막대 소비 검증.
- [2×2 제작](CRAFTING.md): 레시피 채우기·산출물 회수·서버 수량 증거와 실게임 검증 성공.
- [작업대 설치 및 상호작용](WORKBENCH.md): 단일 윗면 설치, 바닥 지지 블록 검사, 블록 관측 및 3×3 화면 진입.
- [인벤토리 제어](INVENTORY.md): 직접 핫바 선택, 오래된 아이템 관측 거절, 클라이언트 증거와 서버 확정 구분.
- [취소 규약](CANCELLATION.md): 실행 잠금과 별도로 취소하며 완료 경합·응답 유실을 구분한다.
- [스킬 등록](SKILLS.md): ID·버전·입력·조건·예산·성공 검증기를 등록하고 관측 스키마 버전도 기록한다.
- [수집 경로 수정](COLLECTION_PATH_FIX.md): 충돌 검사를 유지한 인접 정지 위치 탐색과 제한된 후보 교체.
- [후보 선택 실패 진단](WOOD_FAILURE_DIAGNOSIS.md): 원목이 보여도 거리·높이 제한으로 선택되지 않는 사례.
- [이전 이동 수정](NAVIGATION_FIX.md): 몸체 충돌 여유 폭과 경유점 감속 문제의 수정 이력.

## 남은 제약과 다음 확인

wood는 수평 4블록, 발 높이부터 +2블록의 원목을 선택하며 최대 3행동/60초다.
짧은 평지만 지원하고 점프·계단·장거리 탐험·제작·자동 스킬 학습은 없다.
재시도는 실행 전 no_flat_path 거절에 한해 최대 한 번이며 원래 예산을 공유한다.
연결 단절로 입력 해제 응답을 받지 못하면 취소 확인 실패로 남긴다.

다음 확인은 3×3 나무 도구 제작의 실게임 검증, 수집 반경 확대와 대체 후보 선택 분기의 실게임 재현이다.
새 컴퓨터의 전체 설치 재현도 남아 있다. 원본 관측·에피소드·인증 정보는 Git 제외 경로에만 보관한다.
